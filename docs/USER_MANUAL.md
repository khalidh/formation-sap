# Manuel utilisateur

## Lancement

1. Ouvrir SAP GUI
2. Saisir transaction `ZPUR_REQ`

## Creer une demande

1. Cliquer `NEW`
2. Saisir les champs obligatoires
3. Cliquer `SAVE`

## Afficher une demande

1. Saisir `REQUEST_ID`
2. Cliquer `DISPLAY`

## Modifier une demande

1. Charger la demande
2. Cliquer `CHANGE`
3. Modifier les champs autorises
4. Cliquer `SAVE`

## Supprimer une demande

1. Charger la demande
2. Cliquer `DELETE`
3. Confirmer `YES`

## Rechercher

1. Cliquer `SEARCH`
2. Saisir criteres
3. Cliquer `EXEC_SRCH`
4. Selectionner ligne et `OPEN_REQ`

## Regles visibles

- Quantite > 0
- Prix unitaire >= 0
- Statut dans NEW/APPROVED/REJECTED/CLOSED
- Demande CLOSED non modifiable
