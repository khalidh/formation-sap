# BTP trial limitation

A standard SAP BTP trial account is usually not enough to run a real RAP backend.
The RAP solution requires SAP BTP ABAP Environment (ABAP Cloud).

This repository therefore serves as:

- a migration blueprint from the Dynpro app
- an importable source pack for ABAP Environment
- a documentation set for RAP/Fiori elements training

If your tenant has ABAP Environment, you can execute the project there.
If not, you can still use the sources and docs as a training specification.
